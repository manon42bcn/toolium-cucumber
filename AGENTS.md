# Project instructions

- Write code, comments, docstrings, user-facing strings, and project documentation in English. Test inputs may use localized Gherkin keywords when exercising dialect support.
- Add a docstring to every function and method. Use JSDoc for JavaScript and TypeScript and native docstrings for Python. Explain the purpose and any constraints callers need to know.
- Comment code whose reasoning is difficult to follow, such as parser workarounds or non-obvious boundary conditions.
- Keep the extension and its tests independent of specific consuming repositories. Use invented feature files and step definitions in tests and examples.
